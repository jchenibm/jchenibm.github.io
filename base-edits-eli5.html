动态双态模型
Base + Edits

如果想改动一本 1000 页的厚百科全书，你绝对不会把整本书重新印刷一遍。
你只需要在上面贴一张便利贴！

1. 基础底盘 (Base)

体积巨大、不可修改（Immutable）、被所有人安全共享。比如印好的课本、下载好的操作系统镜像、700 亿参数的 AI 大模型底座。

只读 不可变 大体积 零写入风险
📝

2. 增量补丁 (Edits)

体积极小、只记录“变动了什么”（新增/修改/删除）。修改随时发生在这层，完全不需要碰到底盘哪怕一个字节。

可读写 毫秒级极速 随时丢弃 差量 Delta
⚡️

3. 透光叠加 (View)

当你读取时，系统把两层叠在一起看：有便利贴看便利贴，没便利贴看底板。便利贴攒多了，找个深夜“烘焙”成新底板（Compaction）。

即时生效 Copy-on-Write 定期压实合并

🎮 动手点点看：透明图层工作台

观察左侧的两个分离物理层，如何实时叠加渲染成右侧用户看到的“真实世界”：

底层物理分离 (Physical Storage) Base 永不变，Edits 极轻
用户看到的合成世界 (Logical View) Base ⊕ Edits

现实科技世界里，它无处不在

几乎所有现代高吞吐、高并发、现代计算系统，骨子里都在用这套哲学：
🐳

Docker 容器

OverlayFS 存储驱动

100 个容器同时运行，不需要拷 100 份 Ubuntu 镜像。

Base: 只读镜像层 (Image 500MB，100人共享)
Edits: 容器可写层 (Container Layer 2MB，各玩各的)
🧠

大模型 LoRA 微调

Low-Rank Adaptation

为每个行业微调 AI，不需要重新训练或保存几百个大模型。

Base: 冻结的主模型权重 (70B 参数，140GB 显存)
Edits: 低秩外挂适配器 (LoRA 权重，仅 50MB 随插随拔)
🗄️

LSM-Tree 现代数据库

RocksDB / Cassandra / ClickHouse

每秒写入 10 万次，硬盘磁头不需要来回随机寻道乱找。

Base: 磁盘上压实排序好的历史 SSTable 文件
Edits: 内存里飞速追加写入的 MemTable / WAL
🌿

Git 与版本管理

Commit Snapshot & Working Tree

改一行代码，不需要把整个几万个文件的项目全复制一份。

Base: 上一次保存的提交对象 (Commit Tree)
Edits: 暂存区增量与工作区差异 (Diff / Patch)
🎨

多人实时协同软件

Figma / Google Docs / Notion

你打字时对方瞬间看见，不是每秒互传一次整篇文档。

Base: 文档整点历史快照 (Snapshot)
Edits: 键盘敲击的操作流水广播 (Operation / CRDT)
🏢

SaaS 多租户定制

标准软件 + 租户客制化覆盖

服务 1 万家企业客户，绝不能为每家独立写一套软件源码。

Base: 全平台统一的标准产品功能核心
Edits: 每个租户自选的扩展字段与定制流程 Overlay

💡 一句话终极精髓

把「不变的重量」留给底盘，把「变化的速度」留给补丁。
读取时透过透镜叠加，闲时默默合并压实。这是现代计算机科学打败复杂性与膨胀成本的最美优雅解法。
